# Make the coolest art — make.fun entry

Bounty: https://make.fun/bounty/coolest-art-01 ($250, ends Fri 13 Nov 2026 17:00 WIB)

## The art

An obsidian-armored warrior with glowing molten-gold cracks, standing on a
floating island of broken mirrors above the clouds, facing a colossal phoenix
made of liquid gold fire under a stormy violet sky.

## How it works

`main.py` copies the bundled `entry.png` to `/output/entry.png`, byte for
byte. No network, no randomness — two runs write identical bytes.

## Run

```sh
python3 main.py
```
